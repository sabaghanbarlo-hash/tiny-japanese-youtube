# Kana lessons

One character per video. Run:

    python kana.py kana/hira-a.txt            # full MP4 in output/
    python kana.py kana/hira-a.txt --preview prev --dummy-audio   # check frames fast

Optional mnemonic pictures: assets/mnemonics/<hiragana|katakana>-<romaji>.png (e.g. hiragana-a.png).
See the header of kana.py for the script format. Copy hira-a.txt for each new character.
