VOCABULARY
びょうき (Byouki) - illness (病気)
かぜ (Kaze) - cold (風邪)
いたい (Itai) - painful; hurts (痛い)
くすり (Kusuri) - medicine (薬)
ねつ (Netsu) - fever (熱)
せき (Seki) - cough (咳)
げんき (Genki) - healthy; well (元気)
けが (Kega) - injury (怪我)
ずつう (Zutsuu) - headache (頭痛)
はなみず (Hanamizu) - runny nose; nasal mucus (鼻水)

GRAMMAR
Using あります for symptoms - Use あります to say that you have a symptom or condition. It is a polite, simple way to describe what is wrong.
