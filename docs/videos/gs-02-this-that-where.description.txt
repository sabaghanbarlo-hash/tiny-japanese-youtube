VOCABULARY
これ (Kore) - this / that / that over there
どれ (Dore) - which one
この (Kono) - this / that / that over there (+ noun)
ここ (Koko) - here / there / over there
どこ (Doko) - where
なん (Nan) - what

GRAMMAR
The こそあど system - こ = close to the speaker, そ = close to the listener, あ = far from both, ど = question. これ, それ, あれ, どれ are things. ここ, そこ, あそこ, どこ are places.
これ stands alone, この needs a noun - Use これ by itself: これは ほん です。 Use この with a noun right after it: この ほんは わたしの です。 The same goes for その and あの.
