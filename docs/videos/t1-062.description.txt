VOCABULARY
もんだい (Mondai) - problem; question (問題)
いみ (Imi) - meaning (意味)
ほうほう (Houhou) - method; way (方法)
かんがえ (Kangae) - idea; thought (考え)
ばあい (Baai) - case; situation (場合)
ひつよう (Hitsuyou) - necessary; need (必要)
かんけい (Kankei) - relationship; connection (関係)
けいけん (Keiken) - experience (経験)
もくてき (Mokuteki) - purpose; goal (目的)
げんいん (Gen'in) - cause; reason (原因)

GRAMMAR
Asking “What is it?” - Use “X は 何ですか” to ask what X is. Put the topic before は.
