VOCABULARY
かぜ (Kaze) - wind (風)
ゆき (Yuki) - snow (雪)
くも (Kumo) - cloud (雲)
たいふう (Taifuu) - typhoon (台風)
きおん (Kion) - temperature (気温)
かみなり (Kaminari) - thunder (雷)
たいよう (Taiyou) - sun (太陽)
ほし (Hoshi) - star (星)
あたたかい (Atatakai) - warm (暖かい)
すずしい (Suzushii) - cool; pleasantly cool (涼しい)

GRAMMAR
Using も for “also” - も adds the meaning “also” or “too” to a noun. It shows that something is true as well.
