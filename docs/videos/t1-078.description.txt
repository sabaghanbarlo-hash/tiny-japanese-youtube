VOCABULARY
さそう (Sasou) - to invite (誘う)
どうぞ (Douzo) - please; go ahead
ぜひ (Zehi) - by all means; definitely
いっしょに (Isshoni) - together (一緒に)
だいじょうぶ (Daijoubu) - okay; all right (大丈夫)
いただく (Itadaku) - to receive (humble)
よろしい (Yoroshii) - all right; acceptable (polite)
あく (Aku) - to be free; to become available (空く)
ことわる (Kotowaru) - to decline; to turn down (断る)
ませんか (Masenka) - would you like to…?

GRAMMAR
Asking Permission - Use ても いいですか to ask if an action is allowed. よろしいですか is a more polite way to ask.
